# Fail2ban 26.11.34 交付说明

更新页卡片头重排，版本号换字形。

## 一、卡片头

改之前是「标题一行、按钮靠右」，说明单独占一整行挂在卡片头下面。窄屏上这段说明
先折成两行，卡片头于是散成三块：标题、按钮、说明各占一行。

现在标题与说明叠成一个整体吃掉左侧宽度，按钮固定在右侧顶对齐：

    版本与更新                [打开发布页面]
    读取 GitHub 上的最新发布版本，与当前安装的版本比较。

说明同时改小一档：12px、更淡的一档灰（原来 12.5px、正文档灰），贴着标题往下 5px。

## 二、版本号字形

两个版本号原来挂着 `mono` 类，用的是等宽字体。等宽字形在同样字号下明显更宽更重，
和页面里其它数值不像一套。现在改用与其余数值同一套无衬线字形，
数字仍按 `tabular-nums` 对齐 —— 换版本时位数变化不会让它们左右跳动。

## 三、实测（390×844 视口）

| 项 | 值 |
| --- | --- |
| 卡片头 | 63px 高，不换行，顶对齐 |
| 标题 | 14px / 600 |
| 说明 | 12px，贴在标题下 5px，占满左侧 230px |
| 按钮 | 100×32，右侧 265px 处，与标题顶端齐平 |
| 版本号 | 21px / 600，无衬线，tabular-nums |

桌面 1440 下同样是一行标题 + 说明、按钮在最右，未出现换行。
