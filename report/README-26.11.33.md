# Fail2ban 26.11.33 交付说明

更新页去掉页首那句说明。

## 一、删掉的是什么

    面板会自己检查新版本；发现新版本后可以在这里一键升级。

## 二、为什么删

这句和页面里已有的三处说的是同一件事：

- 页签叫「版本与更新」；
- 卡片标题是「版本与更新」，副标题写「读取 GitHub 上的最新发布版本，与当前安装的版本比较。」；
- 状态条直接给出当前状态（已是最新 / 发现新版本 / 检查失败）与可做的动作（检查更新 / 一键更新）。

三者已经把「谁在检查、有没有新版本、能做什么」讲完了，页首再概括一遍只是重复。
删掉后卡片紧贴页签，上方不再多出一条 20px 的说明行。

## 三、顺带清掉孤儿词条

这句话用的是 `update.hint` 词条。只删渲染语句会留下一条没人引用的 key，
所以中英两本字典里各删一条，避免后续维护时误以为它还在用。

## 四、验证

- 八道本地闸门全通过（含 i18n 字典一致性：此刻两本书的 key 集合仍然一一对应）。
- 桌面与手机两套视口逐页截图，更新页无空白行、无控制台报错。

## 五、发布

已按流程提交、打 tag `v26.11.33` 并推送，由 CI 构建并发布 Release。

## 六、生产机

**未动**。升级由你在应用中心 Web UI 自己操作。
