# Fail2ban 26.11.40 交付说明

全局白名单列表的圆角与间距。

## 一、按需求逐条对照

| # | 要求 | 落地情况 |
| --- | --- | --- |
| 1 | 圆角和上面的搜索框做成一样 | 6px → 10px，与输入框同档 |
| 2 | 和上面离开一点距离 | 加 8px 上边距 |

## 二、原因

列表外框用的是 `--radius-sm`（6px），上一行输入框用的是 `--radius`（10px）。
两者宽度一致又上下相邻，圆角不同会显得像两块错位的部件。

间距方面，列表原先紧贴输入框，两条边框挨在一起被读成一条粗线，看着像长歪了。

## 三、实测

| 项 | 改前 | 改后 |
| --- | --- | --- |
| 输入框圆角 | 10px | 10px |
| 列表外框圆角 | 6px | **10px** |
| 输入框与列表间距 | 0px | **8px** |

390（手机）与 1440（桌面）两个视口测得的数值一致。
