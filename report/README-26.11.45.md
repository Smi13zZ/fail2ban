# Fail2ban 26.11.45 交付说明

「已接管」徽章改用与「启用」同一套样式；手机端补上「接管」列。

## 一、徽章为什么改

「已接管」原先用描边款（透明底 + 文字色边框），旁边「启用」是浅绿底绿字。
并排时像两个不同层级的标记，实际上它们都是这张表的正常状态，不该分主次。

改用 `.badge.ok`：与「启用」「运行中」同一套浅绿底 + 绿字。三个状态并列时
读起来是同一组信息，靠文字区分，不靠样式区分强弱。

描边款当初是为「一行出现好几个标签、全反色会盖过主体内容」设计的。
现在这三个都是状态而非标签，配色跟着「启用」走更合适。

## 二、手机端为什么加

接管列原先带 `hide-sm`，900px 以下整列收起 —— 手机上只能看到「启用 / 运行状态」，
看不出这个 Jail 是不是本应用接管的。而「概览」页与「Jail 管理」页共用同一张表，
两边都受影响。

去掉 `hide-sm` 后接管列在窄屏保留，表格最小宽度从 760px 提到 856px
（多出接管列的 96px）。手机端本来就是横向滚动，多这一列不影响操作。

## 三、实测

| 项 | 结果 |
| --- | --- |
| 三个徽章配色 | 都是 `rgba(22,163,74,0.12)` 底 + `rgb(22,163,74)` 字 |
| 1440×900 表格宽 | 1154px（可用 1186px，不出滚动） |
| 390×844 表格宽 | 856px（容器 368px，横向滚动） |
| 375×667 / 320×640 | 同上，三列状态都在 |
| 英文表头 390px | Managed / Enabled / Run state 均不截断 |
