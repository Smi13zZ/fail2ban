# Fail2ban 26.11.32 交付说明

手机端抽屉侧栏改成从屏幕顶端起算。

## 一、现象

真机上拉开抽屉，导航第一项和侧栏顶部之间空出一大条，看起来像「没有顶头开始」。

## 二、根因

侧栏上有一条 `padding-top: env(safe-area-inset-top, 0px)`，本意是躲开刘海与状态栏。
但抽屉是覆盖在应用窗口之上的，上面那块空间已经被飞牛的外层标题栏占掉了 ——
再垫一遍属于重复让位。iPhone 上安全区是 47px，于是首项被推到 57px 的位置。

这个差在无头浏览器里量不出来：安全区为 0，两边完全一致（都是 10px）。
所以要复现必须把安全区模拟出来。

## 三、改法

- 侧栏去掉 `padding-top: env(safe-area-inset-top)`，导航从屏幕最顶端开始；
- 底部主题 / 语言按钮区的 `env(safe-area-inset-bottom)` 保持不动；
- 其余尺寸沿用上一版对齐后的值（216px / 38px / 40px / 14px）。

## 四、验证

用 CDP 的 `Emulation.setSafeAreaInsetsOverride` 注入 47px 顶部安全区，
再量两个面板抽屉首项距侧栏顶部的距离：

| 场景 | 本产品（改前） | 本产品（改后） | 同产品线 |
| --- | --- | --- | --- |
| 无安全区 | 10px | 10px | 10px |
| 顶部安全区 47px | **57px** | **10px** | 10px |

改后两种场景下首项距顶都是 10px，与侧栏顶部齐平。
