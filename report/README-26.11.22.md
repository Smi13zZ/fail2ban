## 二、滚动条是从哪来的

备份清单与存储明细外面套着一层限高滚动区（`.bscroll`，`max-height: 300px; overflow-y: auto`）。
表格容器 `.table-wrap` 为了铺满卡片左右边缘用了负边距 `margin: 0 -16px -16px`
——它的用途是让**普通卡片里的宽表**能横向滚到卡片边缘，但落进限高盒里就变成了：

| 方向 | 现象 | 原因 |
| --- | --- | --- |
| 横向 | 能左右拖，拖出来的只是留白 | 负的左右边距把内容撑得比盒子宽 16px |
| 纵向 | 能上下拖，最后一行的按钮被切一半 | 负的下边距把内容高度算进了盒子高度之外 |

还有一个放大因素：CSS 里只写 `overflow-y: auto` 时，**另一个方向会被算成 `auto`**，
于是横向也跟着可滚。现在两处一起改：限高盒显式写 `overflow-x: hidden`，
并在 `.bscroll > .table-wrap` 上取消负边距与内边距。

## 三、按钮高度

手机端原先把按钮抬到 44px 是为了触控目标，但代价是同一张卡片里「输入框比按钮高、
小按钮比大按钮矮」，一行里两个控件永远对不齐。现在统一抬一档：

| 控件 | 桌面 | 手机 |
| --- | --- | --- |
| 普通按钮 `.btn` | 36px | 38px（原 44） |
| 行内小按钮 `.btn.sm` | 30px | 32px（原 40） |
| 输入框 | 36px | 38px（原 44） |
| 标签条按钮 | 30px | 30px（不再单独加高） |

标签条按钮保持桌面高度：它已经嵌在分段控件里、上下各留 4px 内边距，
再加高会让整条标签条比卡片标题还厚。
