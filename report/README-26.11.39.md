# Fail2ban 26.11.39 交付说明

全局白名单再调两处。

## 一、按需求逐条对照

| # | 要求 | 落地情况 |
| --- | --- | --- |
| 1 | 列表放到输入框和「添加」那一行的下面 | 输入行在上、列表在下 |
| 2 | 在「删除」左边增加一个「编辑」按钮 | 每行为「地址 · 编辑 · 删除」 |

## 二、现在的样子

    全局白名单 ignoreip
    ┌────────────────────────────────────┐
    │ [ 输入 IP / 网段后回车… ]   [添加]  │
    ├────────────────────────────────────┤
    │ 127.0.0.1/8          [编辑] [删除]  │
    ├────────────────────────────────────┤
    │ ::1                  [编辑] [删除]  │
    └────────────────────────────────────┘

新条目就是从上面这一行加进去的，输入框贴着急要操作的列表。

## 三、行内编辑

点「编辑」后，那一行就地变成「输入框 + 保存 / 取消」，其余行保持只读：

- 回车保存、Esc 取消，与常见的表格内编辑一致；
- 改成与已有条目重复时**拒绝并提示**，不静默丢弃 —— 静默丢弃会让用户以为自己改成功了；
- 一行只放一个地址，多填了同样拒绝；
- 删除条目时同步修正编辑索引：删掉前面的行后，正在编辑的那条不会错位到别的地址上。

## 四、实测（390×844，真机浏览器驱动）

| 步骤 | 结果 |
| --- | --- |
| 初始 | 列表在输入行下方，两行各 51px，每行「编辑(48) 删除(48)」 |
| 点编辑 | 该行变输入框 + 保存/取消，值预填原地址并全选 |
| 改值保存 | 127.0.0.1/8 → 10.0.0.0/8，列表刷新正确 |
| 取消 | 输入 999.999.999.999 后取消，列表不变 |
| 改重复 | 提示「这些条目已经在白名单里了」，停在编辑态不覆盖 |
