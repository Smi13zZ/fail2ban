# Fail2ban 26.11.35 交付说明

全面检查中发现的缺陷：fn-knock 黑名单表在手机上被压垮。

## 一、问题

表格是 `table-layout: fixed`，`IP` 与「操作」两列各定死 180 / 140px，
合计 320px。手机上表格可用宽度只有约 340px，于是剩下「来源 / 备注 / 到期时间」
三列**各被分到 7px**：表头与内容一起消失，行高还被撑到 520px 一行。

界面上看起来是「表格里只剩 IP 和移除按钮，中间空出一大片」。

## 二、修法

1. 给这三列补上宽度（200 / 240 / 150），不再让它们平分剩下的渣；
2. 给表格一个能装下五列的最小宽度，`≤900px` 起改为横向滚动。

第 2 步有个坑：CSS 里已有 `.table-wrap table.fixed { min-width: 0 }`（在 ≤720px 断点），
特异性比 `.fnk-table { min-width: 740px }` 更高，直接写会被盖掉、横向滚动不会出现。
所以选择器写成 `.table-wrap table.fixed.fnk-table`，并放在同一个断点里。

## 三、实测

| 项 | 改前 | 改后 |
| --- | --- | --- |
| 来源列 | 7px | 200px |
| 备注列 | 7px | 240px |
| 到期列 | 7px | 150px |
| 行高 | 520px | 64px |
| 窄屏表现 | 三列不可见 | 横向滚动 |
