## 页面结构

原来是一个工具栏加大卡片，两张分散的块。现在是单卡片，从上到下：

1. **卡片头**：标题「版本与更新」、一句说明、右侧「打开发布页面」按钮直达 Release。
2. **版本对比**：`v当前 → v最新`，发现新版本时右侧版本号着色。
3. **状态条**：圆形图标 + 标题 + 副标题，右侧就是「检查更新」与「一键更新」。
   没有新版本时一键更新**整个不渲染**（不是禁用态）——一个永远点不动的按钮
   放在那里只会让人以为界面坏了。
4. **版本更新说明**：限高 13 行、超出可滚动，长更新日志不会把卡片撑成一屏多。
5. **安装包清单**：只列 .fpk，文件名独占一行，大小靠右。
6. **底部三行**：发布仓库、上次检查、发布时间，最后一行说明自动检查节奏。

状态条只有「发现新版本」才着色（暖色边框 + 淡底 + 星形图标）；
「已是最新」与「检查失败」都走中性色——前者是正常状态，把它染绿会让
一件本该无声的事情看起来像需要处理。

## 顺带修掉的两个显示问题

**「检查于 {t}」把模板占位符原样留在了界面上。** 那次 `checkedAt` 的文案是带
`{t}` 占位符的模板，代码却直接把渲染结果当标签用了。改成另加一个不带占位符的
`update.checkedLabel` 作标签，值再用 `t(key, {t: ...})` 传参。

**本地版本高于线上最新时「最新版本」显示更低的号。** 装了还没发布的内测包时，
左边 26.11.10、右边 26.11.9 会让人以为要降级。现在版本号按数值逐段比较
（字符串比较会把 `26.11.10` 判成低于 `26.11.9`），线上更低时右侧直接跟当前版本对齐。
