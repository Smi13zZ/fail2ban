## 四点说明

**图标是同一套笔触。** 18px、1.8 线宽、圆角端点，和面板内其它图标一致。主题三态的「跟随系统」
用显示器而不是半明半暗的圆：圆形在 18px 下两种填充糊在一起，看不出表达什么。

**版本行加了引擎版本。** 面板版本和系统里实际装的 fail2ban 版本经常不同步——面板升级不会
带走系统里的引擎。排查「面板显示已封禁但规则没生效」这类问题时，两个版本要同时能看到。
取不到时（没装 fail2ban）只显示面板版本，不留占位符。

**字号收到 11px 等宽是量出来的。** `v26.11.7 · Fail2ban 1.0.2` 共 25 个等宽字符，
216px 侧栏里可用宽度约 170px；12px 会溢出成省略号（实测 `Fail2ban 1....`），
11px 实测 `scrollWidth == clientWidth == 165`，正好放得下。

**收起状态保持方形。** 62px 轨道里并排放不下两个按钮，改成竖排；但按钮本身不拉伸，
仍是 34×34 —— 拉成 46px 就不再是方形，和图标按钮的形态对不上。
