# Fail2ban 26.11.44 交付说明

手机端存储页「空间占用」的刷新按钮挪到标题右侧，与标题同一行。

## 一、原因

窄屏的卡片头默认是「标题独占整行、动作换到下一行」。这条规则是给带分段控件
或两个以上按钮的卡片用的 —— 那里确实需要一整行来摆。

存储页这张卡只有一个「刷新」，照那条走就白占一整行：标题下面孤零零一个按钮，
看着像是在操作整个页面，而不是刷新这张卡。

## 二、改法

改用已有的 `.ch-inline` 卡片头型：窄屏下标题吃剩余宽度、超长省略，
按钮固定宽度留在右侧。桌面端本来就是这一排法，没有任何变化。

改动只有一处 —— `storageHtml()` 里给 `cardHead()` 加第三个参数 `'ch-inline'`。
没有动 `.card-head` 的窄屏基础规则，其他卡片不受影响。

## 三、实测

| 宽度 | 卡片头高度 | 标题与按钮 | 页面溢出 |
| --- | --- | --- | --- |
| 390×844 | 32px（原 60px） | 同行 | 0 |
| 375×667 | 32px | 同行 | 0 |
| 320×640 | 32px | 同行 | 0 |
| 1440×900 | 30px（未变） | 同行 | 0 |

英文界面（Disk usage / Refresh）在 320px 下标题不截断。
