# Fail2ban 26.11.46 交付说明

Jail 表「运行状态」列去掉「运行中」前面那个小圆点。

## 一、原因

26.11.45 把「已接管」改成与「启用」同款纯文字徽章之后，这一行只剩「运行中」
还带圆点：三列并排时前两个是纯文字、第三个前面多一个点，看着像它比前两个
多标了一层状态。

## 二、改法

词条 `dash.badgeRunning` 的值去掉 `<span class="dot">`：

    改前  <span class="badge ok"><span class="dot"></span> 运行中</span>
    改后  <span class="badge ok">运行中</span>

反查表里原先两条源文（带点 / 不带点）分别映射到 `dash.badgeRunning` 与
`notify.badgeRunning`。现在带点的那条不存在了，两条源文合并成一条，
`notify.badgeRunning` 记进 `SRC2KEY_ALT` 候选清单，不留重复的源文键。

## 三、没动的地方

圆点本身在别处是有意义的：

| 位置 | 为什么保留 |
| --- | --- |
| 顶栏服务徽章 | 窄屏收起文字后只靠圆点还原本显示 |
| 通知页渠道列表的运行中 | 单独一列，没有相邻徽章可比 |

## 四、实测

| 徽章高度 | 22px | 22px |
