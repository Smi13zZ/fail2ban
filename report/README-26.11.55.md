# Fail2ban 26.11.55 交付说明

维护页的备份清单改成「可用备份」列表，可上下滚动。

## 一、问题

列表原本也在 `.bscroll` 里（`max-height: 300px; overflow-y: auto`），但看着既
不能滚、也不像能滚：

1. **300px 除不尽行高** —— 表头 36 + 行 42，300 会切出半行，最后一行按钮被裁一半；
2. **表头 sticky 失效** —— `.table-wrap` 自带 `overflow-x: auto`，它自己变成了
   滚动容器，而它并不纵向滚动，于是表头的 `sticky` 粘在它身上、跟着内容一起滚走；
3. **滚动条不显眼** —— 只露 5 行时看不出下面还有。

## 二、改法

| 项 | 改前 | 改后 |
| --- | --- | --- |
| 视口高度 | 300px（切半行） | **246px** = 36 + 5×42，整 5 行 |
| 表头 | 跟着内容滚 | 固定，只在列表内滚 |
| 滚动条 | 默认细线，无样式 | 6px 常显，悬停加深 |
| 超出提示 | 无 | 底部「共 N 份，列表内上下滚动查看全部」 |
| 手机端 | 同样 300px | 同样 246px |

**技术上关键一步**：给 `.bscroll > .table-wrap` 加 `overflow: visible`。
它原本的 `overflow-x: auto` 会截断 `position: sticky` 的参照容器，表头因此粘不住。
滚动交给外层 `.bscroll`，内层不参与。

## 三、实测

| 项 | 结果 |
| --- | --- |
| 桌面 1440 | 视口 246px、12 行内容 540px、`scrollTop` 可写到 63 |
| 手机 390 | 同上；表头距容器顶 0px（真粘住） |
| 5 行完整露出 | 是（第 6 行不露半截） |
