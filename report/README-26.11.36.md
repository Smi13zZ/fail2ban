# Fail2ban 26.11.36 交付说明

fn-knock 联动页两处调整。

## 一、按需求逐条对照

| # | 要求 | 落地情况 |
| --- | --- | --- |
| 1 | 手机端「刷新列表」放到「敲门黑名单」右边 | 与标题同一行、靠右；不再单独占一行 |
| 2 | 把每个状态底下的灰框去掉 | 键值清单里的徽章去掉胶囊底与内边距，只留文字色 |

## 二、「刷新列表」与标题同行

窄屏的卡片头规则原本是「标题独占整行、动作换到下一行」——那是给分段控件腾地方用的。
「敲门黑名单」右侧只有一个「刷新列表」，也照这条走就浪费了整整一行高度，
而且按钮掉到标题下面，读起来像整页的操作，其实它只影响下面那张表。

新增一个 `.ch-inline` 卡片头型：标题吃剩余宽度、超长按省略号收，
按钮固定宽度留在右侧。**只给这一处用**——其余五处带按钮的卡片头维持原样，
避免顺手改掉别处的排布。

## 三、去掉状态标签的灰框

运行状态页那五行（安装情况 / 数据目录 / 管理后端 / 本地密钥 / fail2ban）的值
原来是胶囊徽章，自带灰底。整列排下来像斑马条，反而更难读。

现在 `.kv` 里的徽章：

- 去掉底色、边框与内边距；
- 高度 22px → 16px，与相邻的纯文字行同高；
- 只靠文字色区分：绿=正常、橙=异常、灰=未就绪。

着色规则**只在 `.kv` 内生效**。表格与工具栏里的徽章仍是原来的胶囊样式——
那里多个标签并排，底色承担的是「扫一眼就能分堆」的作用，去掉反而看不清。

## 四、实测

| 项 | 结果 |
| --- | --- |
| 手机端卡片头 | 标题与按钮同一行，标题超长省略 |
| 桌面端卡片头 | 不变（按钮本来就在右侧） |
| 徽章底色 | `transparent`，无边框，padding 0 |
| 徽章高度 | 22px → 16px |
| 深色主题 | 绿 rgb(74,222,128) / 橙 rgb(251,191,36) / 灰 rgb(161,161,161)，清晰可辨 |
| 浅色主题 | 绿 rgb(22,163,74) / 橙 rgb(245,158,11) / 灰 rgb(115,115,115)，清晰可辨 |
