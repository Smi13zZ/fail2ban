## 开发中修掉的几个真实缺陷

**1. 外壳文案完全漏翻（P0）**
第一版只处理了 `app.js`，结果切英文后正文变英文、但侧栏导航和顶栏按钮仍是中文 ——
因为那些文字写在 `index.html` 里。加 `data-i18n` + 回填逻辑才补齐。

**2. 运行时长永远是中文（P0）**
后端把「3 天 23 小时」拼成一个中文字符串返回，前端无从翻译。改成返回结构化数值。

**3. 备份位置标签同理**
后端拼了「{volume}（存储空间根目录）」，改为返回 `kind` + 变量，前端按语言拼。

**4. 我自己写坏过 app.js 两次**
用逐字符扫描器做批量替换时，转义判断失误导致引号配对错位，吞掉 60 行代码。
根因是两个叠加因素：文件是 **CRLF 行尾**（正则里 `[^'\n]` 不给 `\r` 留位置会跨行匹配），
以及自写扫描器对 `\\` 的处理不严谨。
最终方案：**处理前统一转 LF、用正则一次匹配完整字面量、写盘前先 `new vm.Script()` 解析校验**。
两次都是从 26.11.2 的包里还原后重做的，没有交付坏版本。
