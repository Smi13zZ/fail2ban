# Fail2ban 26.11.54 交付说明

修两处「有新版本」红点。

## 一、侧栏那颗一直不显示

结构上它是导航项末尾的 `<span class="nav-badge nav-alert">` —— 与「封禁数」那个
数字徽标共用同一个元素。被两条规则吃掉：

1. `.nav-badge:empty { display: none }`（特异度 0,2,0）压过单写的 `.nav-alert`，
   空元素直接不渲染 —— 这是「根本不显示」的直接原因；
2. 激活行的 `.nav button.active .nav-badge`（0,3,1）把背景换成反色药丸，
   即便显示出来也是个灰点。

### 改法

选择器写成 `.nav button .nav-badge.nav-alert` 系列，把调用点的三种写法一起列上，
并显式带上 `:empty`；尺寸、内边距、底色、字号全部覆盖回红点形制。
2px 同色描边让它在普通行与反色的激活行上都看得清。

收起侧栏时贴右缘、垂直居中，与展开态同一读法（都在行尾）。

## 二、设置页「更新」标签那颗跑到右上角

原先它是标签文字后面的普通 flex 子项：占宽度、并与标签之间留出 5px 的 `gap`，
看起来像「更新 ・」多了个字符。

改成 `.workbar button { position: relative }` + 绝对定位到右上角（top/right 各 4px），
不占标签宽度，也不会被长标签挤走。与参考实现的位置一致。
