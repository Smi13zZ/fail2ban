# Fail2ban 26.11.38 交付说明

全局白名单改成逐行列表。

## 一、改前

每个地址是一颗红底色胶囊、等宽字体、右端嵌一个 18px 的 ✕。
三个以上地址堆在一起时，色块彼此挤着，既看不出边界也扫不了顺序；
✕ 只有 18px，手机上很难点准。

## 二、改后

    全局白名单 ignoreip
    ┌──────────────────────────────┐
    │ 127.0.0.1/8            [删除] │
    ├──────────────────────────────┤
    │ ::1                    [删除] │
    └──────────────────────────────┘
    [ 输入 IP / 网段后回车…  ]  [添加]

- 一行一个地址，行与行之间一条细线，外框圆角与输入框同一档；
- 地址左对齐、等宽字体，窄屏允许逐字符折行——IP / 网段是逐字符读的，折行比截断成省略号好核对；
- 删除按钮用常规描边小按钮，手机上 32px 高，点得准；
- 输入框与「添加」在列表下方，输入框吃剩余宽度、按钮按内容宽。

## 三、顺带补的样式

输入行（`data-chip-add`）原先没有任何规则。输入框按自身固有宽度（约 166px）占位，
窄屏上会把「添加」按钮挤出容器。补上 `min-width: 0` 与弹性宽度后正常。
