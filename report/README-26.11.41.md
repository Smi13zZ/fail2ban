## 二、改前的问题

窄屏的卡片头规则是「标题独占整行、动作换到下一行」。这两张卡各只有一两个按钮，
照这条走就白占一整行；按钮落到标题下面，读起来也像整页的操作而不是这张卡的。

空态那边更明显：一句话被拆成两处 ——

    空态里：「还没有配置通知渠道。支持钉钉、企业微信群机器人、」
    （整片空白）
    底部：「企业微信应用消息、飞书、Bark、Slack 与自定义 Webhook。」

## 三、改后

    通知渠道                       [+ 添加渠道]
    ┌────────────────────────────────────────┐
    │              🔔                        │
    │      还没有配置通知渠道。               │
    │                                        │
    │  支持钉钉、企业微信群机器人、企业微信    │
    │  应用消息、飞书、Bark、Slack 与自定义    │
    │  Webhook。                             │
    └────────────────────────────────────────┘

    投递记录                [刷新] [清空记录]
    [ 全部 | 成功 | 失败 ]
    每次推送都会留痕……

三个筛选单独一行：三个筛选加两个动作共五个控件挤在 390px 的一行里会被压成短短几截，
标题也会被挤回第二行。

## 四、顺带清掉三条孤儿词条

重构后 `notify.channelsEmpty1` / `channelsEmpty2` / `channelsEmpty2b` 都不再被引用
（`channelsEmpty2b` 更早就是孤儿），已从中英两本字典与反查表里一并删除。
其中两条的译文还带着 `</div>` —— 如果留着，哪天又被引用就会重现 26.11.37 修过的那个「界面上印出 </div>」问题。
